Claude Code

Comprobando…

Al vincular, Glass Island añade unos avisos (hooks) a la configuración de Claude Code de este equipo para saber cuándo está trabajando, cuándo termina y cuándo te necesita. No se usa tu cuenta ni tu contraseña, y nada sale de tu PC. Afecta a las sesiones de Claude Code que abras después de vincular.

Consumo del plan

El consumo (límite de 5 horas y semanal) lo entrega Claude Code a su barra de estado. Al activarlo, Glass Island se configura como barra de estado de Claude Code: verás una línea con el modelo y los porcentajes dentro de Claude Code, y los mismos datos en la isla. Solo se actualiza mientras usas Claude Code, y requiere un plan Pro o Max.
